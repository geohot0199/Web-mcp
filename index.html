Quick tiers
Orbit connection

Connect Orbit — no API keys

No accounts, no API keys, no provider forms. One click connects the studio to Orbit's planning model for open-ended creative builds. There is no credential to store, lose, or leak — the connection lives in this tab's memory only. When you send a creative request, your scene objects (geometry, positions, materials, colours, tags) and remembered design preferences are sent to the Orbit connection so it can propose changes.

Orbit connection off

Orbit's local deterministic agent keeps working without it.

Connecting asks for no key and no sign-in, so nothing sensitive is ever written to storage — the connection is held in memory for this tab and cleared on refresh/close. When you ask Orbit to build something, your current scene (objects, geometry, materials, colours, tags, constraints, and remembered preferences) is sent to the Orbit connection so it can propose a plan. If the connection is unavailable, every request falls back to the deterministic local planner automatically.
